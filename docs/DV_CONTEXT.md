# DV 背景与实体链接上下文

最后更新：2026-06-01

本文档集中维护 DVEntityLinking 中与 DV 相关的背景、实体域假设、真实内容确认规则和 Mock 策略。项目总览只引用本文档，不重复维护 DV 细节。

## 背景参考

以下内容来自历史项目 `DVOpsClaw` 中的高层背景记录，在本项目中作为参考事实使用；如后续涉及真实 DV 数据、字段或接口，仍需重新确认：

- DV 指 `DigitalView-SW`。
- DV 前身是 `I2000`。
- DV 是面向运营商领域的电信软件网管系统。
- DV 已有基础能力，也已有部分 AIOps 能力。

## 本项目关注的实体链接问题

DVEntityLinking 关注的不是单点问答，而是为多个智能任务提供统一实体底座：

- 用户 Query 中出现的实体名称、别名、缩写、编号、告警名、资源名或业务对象，需要被识别和归一化。
- 故障 Agent 在诊断链路中引用的告警、KPI、拓扑、日志、案例和知识对象，需要能链接到同一实体上下文。
- 运维 Copilot 的查询任务需要能从自然语言映射到明确的实体、实体类型、查询目标和相似对象。

## 候选实体域

以下为项目级实体域视图。除已在 V0/V1 明确确认或作为 Mock baseline 使用的范围外，其余仍不是已确认的真实 DV 实体清单：

| 实体域 | 示例方向 | 状态 |
| --- | --- | --- |
| 网络资源实体 | 网元类型、网元实例、站点、小区、链路、板卡、端口、接口、拓扑节点 | V2 已确认拆为 `ne_type` 和 `ne_name`；`ne_type` 可预置并从 DVKnowledge 挖掘，`ne_name` 来源为文件驱动运行时接口 Mock；具体样例内容和字段仍需确认 |
| 告警与事件实体 | 告警码、告警名称、告警实例、事件、incident | V1 已确认 `alarm` 告警知识实体；不建模告警实例事件 |
| 性能与指标实体 | KPI 测量任务名称、测量对象、测量指标、计数器、异常模式 | V2 已确认拆为 `kpi_task_name`、`kpi_meas_objects`、`kpi_meas_type_key`；来源包含 DVKnowledge 挖掘后的预置配置和运行时接口 Mock，具体内容仍需确认 |
| 业务与服务实体 | 服务、客户、业务路径、SLA 对象 | 未进入 V0/V1 baseline，待确认 |
| 运维知识实体 | Runbook、知识条目、案例、故障模式、根因类型 | V0 使用 L0 抽象合成样例验证；真实 DV 字段和接口仍需确认 |
| 流程对象实体 | 工单、变更、派单、处理动作 | 默认不进入 V0 写操作范围，需确认 |

## Mock 分层策略

| 层级 | 名称 | 说明 | 适用阶段 |
| --- | --- | --- | --- |
| L0 | 抽象合成 Mock | 使用明显虚构的实体、Query 和关系，验证算法与接口形态。 | 项目初始化、早期需求和离线测试 |
| L1 | 脱敏样例 Mock | 使用用户提供并确认可用的脱敏样例，保留字段结构或业务语义。 | V0/V1 demo 和评测 |
| L2 | 模拟接口 Mock | 用本地服务模拟 DV 接口返回，字段和错误语义需用户确认。 | 接口联调前的能力穿刺 |
| L3 | 真实 DV 只读接入 | 连接真实 DV 只读接口或数据源。 | 需正式确认、设计和安全约束 |

当前默认层级：V0 baseline 为 L0；V1 alarm-only demo 使用最小字段样例，项目内样例内容按用户确认可提交处理；V2 启动 L2 文件驱动运行时接口 Mock，用于模拟 `ne_name` 和 KPI 运行时数据。真实 API key、本地配置和完整请求响应日志仍不得提交。

## 需要触发用户确认的事项

- 真实 DV 实体类型、字段名、字段含义和枚举值。
- 真实 DV 查询接口、返回结构、错误码、分页、权限和限流。
- 真实告警、KPI、拓扑、日志、工单、案例或知识库样例。
- 是否允许用某类脱敏数据作为 demo 样例。
- 是否允许保存 LLM 输入输出、实体链接中间结果或运行输出。
- 是否把某个 Mock 行为视为未来真实 DV 能力的代表。

## V0 推荐最小样例

V0 可先构建一组 L0 抽象合成样例，用来验证端到端能力：

- 20 到 50 个实体，覆盖 3 到 5 个实体类型。
- 每个实体包含标准名、别名、类型、外部 ID、描述和少量关系。
- 10 到 20 条 Query，覆盖精确匹配、别名匹配、模糊匹配、歧义消解和无匹配降级。
- 5 到 10 条相似度检索用例，覆盖名称相似、语义相似、关系相近和故障模式相近。

这些数量不是验收标准，只是需求分析前的讨论起点。
