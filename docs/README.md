# DVEntityLinking 文档导航

最后更新：2026-06-26

本目录采用精简文档结构：当前状态和规则放在少量权威文档中，IR/SR 主输出件按版本保留，关闭版本、验收候选版本或撤回验收候选只保留一份 release/acceptance record。评审输入、闭环输入、临时过程记录和重复 README 已合并或清理；需要过程细节时通过 Git 历史追溯。

## 维护规则

- 当前状态只更新 [PROJECT.md](./PROJECT.md)，避免在多个 README 里重复写状态。
- 用户确认和关键决策只追加到 [current/DECISIONS.md](./current/DECISIONS.md)。
- 新版本关闭、进入验收候选或撤回验收候选时新增或更新 `docs/releases/Vx.md`；当前补救迭代所需的 review/disposition/closure 文件按版本放入 `docs/baselines/Vx/` 并在本导航登记。
- IR、SR 主输出件按版本保留在 `docs/baselines/Vx/`。
