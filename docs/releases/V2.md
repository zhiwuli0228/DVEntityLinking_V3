## 验收范围

- Unified catalog 覆盖 25 个实体：9 个 V1 `alarm`，以及 16 个 V2 新增实体。

- V2 Query 样例共 12 条，全部为英文，覆盖 linked、partial、no_match 和 not_required。
- 支持单 Query 多 mention，含 alarm + KPI 同 Query 回归样例。
- V2 evaluation 输出 query-level、mention-level 和 type-level 指标。
- Web 工作台展示 runtime status、Query、多 mention strip、候选、实体详情、catalog filter、safe LLM explanation、negative states、debug collapsed 和 browser evidence。
- 默认验收模式为 `offline_demo`，不依赖真实 DV 接口或真实 LLM。
