## 关键决策

- V1 只覆盖 `alarm` 告警知识实体，不建模告警实例事件。
- V1 样例保持最小字段，不保留 `data_layer`、`can_commit`、`sensitive_level` 等非核心字段。
- V1 每个 Query 最多一个实体词，但必须支持一个实体词对应多个实体的歧义场景。
- 检索策略采用 Python 内存索引优先，不引入三方检索组件。
- 验收同等关注准确率和召回率，必须覆盖无法匹配和不需要匹配场景。
- Web 页面默认突出核心实体链接信息，完整 JSON 仅保留为折叠调试内容。

## 不进入 V1 的事项

- 真实 DV 运行时接口接入。
- 告警实例事件建模。
- `alarm` 以外实体类型。
- 多实体 Query。
- 生产级向量库、FTS 或外部检索组件。
- 默认真实 LLM live smoke 和完整 LLM 请求响应归档。

## 后续

后续新增实体类型、真实 DV 运行时数据、规模化检索、真实 LLM live smoke 常态化或多实体 Query 均应进入 V2 或新的变更流程。
