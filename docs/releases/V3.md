## 验收范围

- Redis Mock：实体词 key 到单实体 ID value；key scope 为 `canonical_name` + confirmed aliases；冲突、dangling ID 和错误 metadata fail-closed。
- 高斯 Mock：结构化实体数据存储，支持按 entity ID 查询；duplicate ID、缺失必需字段和 schema 错误 fail-closed。
- NER pipeline：覆盖 query validation、need-linking、mention detection、normalization、storage lookup、candidate construction 和状态聚合。
- 状态语义：覆盖 linked、partial、no_match、not_required、invalid_input。
- Web/API：默认单入口支持 `--storage-mode v3_mock`，返回 storage-backed trace projection。
- 样例：复用 V1/V2 已确认样例，并新增 V3 Redis/Gauss Mock artifacts 和 NER golden cases。
- 安全：不提交真实 Redis/Gauss 连接串、账号、密码、token、真实 DV payload 或完整 LLM 请求响应。
